# Francisco Estrada

## Automatización, datos y mejora de procesos

Profesional en Ingeniería en Sistemas, especializado en **Power Platform**, análisis de datos, gobierno de datos y optimización de procesos. Combino experiencia operativa y técnica para convertir necesidades del negocio en soluciones medibles, trazables y sostenibles.

Actualmente coordino iniciativas de **Datos Maestros** y **Service Desk** en entornos regionales. Mi trabajo incluye el levantamiento de requerimientos, definición de controles e indicadores, automatización de tareas e integración de información entre sistemas empresariales.

## Servicios tecnológicos

- **Automatización con Microsoft Power Platform:** diseño de aplicaciones en Power Apps y flujos de trabajo con Power Automate.
- **Análisis y visualización de datos:** tableros ejecutivos, indicadores y seguimiento de SLA/OLA con Power BI y Power Query.
- **Gobierno y calidad de datos:** taxonomías, catálogos, depuración, reglas de negocio y políticas para datos maestros.
- **Integración de sistemas:** conexión de APIs y fuentes como JD Edwards, Aranda, SQL Server y Oracle.
- **Gestión de servicios de TI:** organización de Service Desk, controles operativos y prácticas orientadas a ITIL.
- **Mejora de procesos:** documentación, rediseño y automatización para reducir trabajo manual y fortalecer la trazabilidad.
